# ICPC — ACM ICPC

## Detailed Overview
- **Organiser**: ICPC Foundation
- **Primary Category**: Competitive Coding Platform
- **Difficulty Tier**: Elite
- **Target Career Path**: Software Engineer
- **Optimal Attempt Timeline**: 3rd year
- **Brief Details**: World's most prestigious team CP contest; IIT/NIT qualification → Asia Regional → World Finals

---

## 1. 📚 SYLLABUS
- **Programming Language**: Mastery of C++, Java, or Python (C++ is highly recommended for speed).
- **Data Structures**: Arrays, Linked Lists, Stacks, Queues, Hash Tables, Trees (BST, AVL, Segment Trees, Fenwick Trees), Graphs (Representations, Traversals).
- **Algorithms**: Sorting, Binary Search, Sliding Window, Two Pointers, Greedy Algorithms, Dynamic Programming (1D, 2D, Bitmasking), Graph Algorithms (BFS, DFS, Dijkstra, Bellman-Ford, Kruskal, Prim, Floyd-Warshall), String Algorithms (KMP, Trie), Number Theory (GCD, Sieve of Eratosthenes, Modular Arithmetic).

---

## 2. 📝 EXAM PATTERN
- **Sections**: Coding problems only.
- **Total Marks**: Points based on problem difficulty (A, B, C, D, E etc.).
- **Duration**: 2 to 3 hours per contest.
- **Negative Marking**: No negative marks, but penalties (usually 10–20 mins added to completion time) for incorrect submissions (WA, TLE, MLE, RE).
- **Weightage & Priority**: Harder problems yield higher points. The priority is solving more problems in less time with fewer wrong submissions.

---

## 3. 🎓 ELIGIBILITY
- **Academic Criteria**: B.Tech <5 yrs enrolled
- **Age Limit**: None (except for ICPC which has a 5-year enrolment window since starting college).
- **Attempt Limits**: Unlimited contests online.
- **Branch Restrictions**: None. Open to all engineering and non-engineering branches.

---

## 4. 🎯 RECOMMENDED SCORE / CUTOFF
- **Target Milestones**:
  - Codeforces: Specialist (1400+ rating) or Pupil (1200+ rating) for entry-level tech roles.
  - LeetCode: Top 10% rating or 300+ solved problems.
  - CodeChef: 4-Star (1800+ rating) or above.
  - ICPC: Regional qualification requires top 1-2 rank per college in online preliminaries.

## 6. 💡 TOP 5 TIPS
1. Understand the time complexity limits (e.g., N <= 10^5 means O(N log N) or O(N) is required).
2. Up-solve: Always solve at least one problem that you couldn't solve during the live contest.
3. Master Standard Template Library (STL in C++) or Collections Framework (Java) to speed up code implementation.
4. Write modular code and design custom test cases to catch edge cases (like zero, negative numbers, overflow).
5. Focus on reasoning first; don't write code until you have dry-run the logic on paper.

---

## 7. ⚠️ COMMON MISTAKES
- Copying code from online tutorials during live rounds (leads to plagiarism bans).
- Starting with hard problems directly instead of building a strong foundation in basic math and arrays.
- Focusing on the number of solved questions rather than understanding the underlying algorithm.

---

## ⏳ TIMELINE & DURATION
- **Preparation Timeline**: 6 to 12 months of daily coding practice.

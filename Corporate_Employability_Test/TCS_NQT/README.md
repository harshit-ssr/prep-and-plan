# TCS NQT
> **Organizer:** Tata Consultancy Services (TCS) | **Type:** Corporate Employability Test / Recruitment Drive | **Frequency:** Annual / Bi-annual (Free drives) | **Difficulty:** Beginner to Intermediate

This folder contains resources and blueprints for preparing for the **TCS National Qualifier Test (NQT)**. Achieving an elite score in this integrated exam serves as a high-yield recruitment pipeline for TCS's three major engineering roles (Ninja, Digital, and Prime).

## Quick Facts
| Field | Details |
|---|---|
| **Eligibility** | Full-time B.E. / B.Tech / M.E. / M.Tech / MCA / M.Sc graduates from any branch. Minimum aggregate of 60% or 6.0 CGPA across Class X, XII, Diploma (if applicable), and Undergraduation. No rounding up permitted (e.g., 59.9% is ineligible). |
| **Backlogs & Gaps** | Strictly 0 active backlogs at the time of the selection process and onboarding. Maximum cumulative academic gap of 24 months across the entire educational trajectory (must be declared). B.Tech must be completed within the standard 4-year duration. |

| **Attempts** | Unlimited attempts within the age and batch constraints, subject to corporate cooling-off periods (free national drives typically occur once/twice a year). |
| **Score Validity** | Valid for 2 years (standard paid NQT scores, though free drive placement opportunities apply to the current recruitment cycle). |

## Exam Pattern
The TCS NQT is a 190-minute in-center assessment conducted on the TCS iON platform. It has two macro-sections with rigid sectional time limits and **no negative marking**. Inter-sectional and sub-sectional navigation is disabled.

* **Part A: Foundation Section (75 Minutes):** Acts as the primary gating mechanism. Failing this section disqualifies the candidate.
  * *Verbal Ability (25 Questions / 25 Minutes):* High-speed reading comprehension, syntactical accuracy, and lexical reasoning.
  * *Numerical Ability (20 Questions / 25 Minutes):* Arithmetic, statistics, probability, kinematics, and data interpretation.
  * *Reasoning Ability (20 Questions / 25 Minutes):* Seating arrangements, coded relations, syllogisms, and spatial reasoning.
* **Part B: Advanced Section (115 Minutes):** Gating mechanism for premium Digital and Prime offers.
  * *Advanced Quantitative & Reasoning (14–16 Questions / 25 Minutes):* High-friction algebraic progressions, combinatorics, and data sufficiency puzzles sharing a pooled timer.
  * *Advanced Coding (2 Questions / 90 Minutes):* Algorithmic challenges evaluated for correct execution, edge-case coverage, and time/memory complexity constraints.

## Syllabus
* **Foundation Numerical & Reasoning Ability:** Number systems (HCF/LCM, divisibility), commercial math (interest, profit/loss), logistics (time-work, speed-distance), arrangements (circular/linear), blood relations, and visual logic (Venn diagrams, cube folding).
* **Foundation Verbal Ability:** Reading Comprehension (RC), para-jumbles (sentence rearrangements), grammar checks (subject-verb agreement), and cloze tests.
* **Advanced Quant & Reasoning:** Permutations, combinations, progressions (AP/GP/HP), algebra, trigonometry, data sufficiency, and multi-tier puzzles.
* **Advanced Coding:** Array operations (Kadane's, rotations), string manipulation (anagrams, palindromes, ASCII logic), number theory algorithms (GCD, Fibonacci, base conversions), and core searching/sorting.

## Target Score (General Category)
* **Ninja Profile (~₹3.36 LPA):** Aim for 65%–70% accuracy (40–45 / 65 correct questions) in the Foundation section. Advanced sections are not strictly evaluated for this role.
* **Digital Profile (~₹7.00 LPA):** Secure a strong Foundation score (50+/65 correct) + 10+ Advanced MCQs correct + 1 coding question fully executed with all hidden test cases.
* **Prime Profile (₹9.00 – ₹12.26 LPA):** Secure an exceptional Foundation score (55+/65 correct) + 12+ Advanced MCQs correct + both coding questions flawlessly executed.

## Preparation Timeline (3-Month Scratch Plan)
* **Month 1: Foundation & Algorithmic Baseline:** Master core arithmetic/reasoning shortcuts to bypass on-screen calculator dependency. Solve 2 daily RCs. Start the *Take U Forward* 100-question coding sheet (1-2 basic problems/day).
* **Month 2: Advanced Expansion & Sectional Endurance:** Increase coding to 3-4 DSA problems daily (arrays, strings, recursion). Tackle higher math (probability, combinatorics). Start weekly timed sectional mocks to build pacing.
* **Month 3: Simulation & Error Analytics:** Execute weekly full 190-minute NQT mock exams. Analyze errors in sectional timers. Optimize code solutions for O(N) or O(N log N) limits. Focus the last 2 weeks entirely on verified PYQs.

## Top 5 Tips
1. **Target Premium Cadres Asynchronously:** Over-preparing for Advanced Coding sharpens your logic, guaranteeing a high Foundation score as a byproduct while unlocking ₹7.0L+ packages.
2. **Exploit the Absence of Negative Marking:** Leaving a question blank is a major error. If time is running out, guess answers immediately to capitalize on free points.
3. **Prioritize Execution Over Elegance:** Avoid complex data structures. Optimized array manipulations or brute-force hash-maps that pass all base/hidden test cases are sufficient.
4. **Questions-First Heuristic for RC:** In Verbal Ability, read the questions first to identify key proper nouns or variables before scanning the dense passage text.
5. **Relentlessly Practice Sectional Locks:** Simulate tests using portals with rigid navigation timers. You cannot navigate backward or switch sections, so pacing must be second nature.

## Common Mistakes to Avoid
* **Neglecting Verbal & Aptitude:** Over-focusing on coding while failing basic English grammar or reasoning gates, resulting in automated disqualification.
* **Miscalibrated Preparation:** Studying from CAT or banking resources. NQT requires a specific mid-tier analytic rigor paired with high-speed processing.
* **Ego-fighting "Time Sinks":** Wasting 6+ minutes on complex multi-variable arrangements. Skip high-friction questions early and secure easy points first.
* **Bureaucratic Data Mismatch:** Entering incorrect or rounded-up CGPA metrics in the NextStep portal, leading to revocation of offers during background verification.
